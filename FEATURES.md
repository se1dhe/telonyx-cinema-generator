# TELONYX Cinema Generator - Feature List

## MVP

- Upload source video.
- Upload music track.
- Set focus prompt, for example Darth Vader.
- Set target duration.
- Create vertical 1080x1920 edit.
- Add cinematic color filter.
- Add music to final video.
- Check job status.
- Download final MP4.

## Core editing features

- Smart scene scoring.
- Auto cut selection by motion, faces and visual intensity.
- Beat-based cutting.
- Vertical crop presets: 9:16, 1:1, 16:9.
- Action centering.
- Face centering.
- Safe-zone preview for Shorts and TikTok.
- Auto transitions.
- Glitch transitions.
- Whip pan transitions.
- Flash transitions.
- Film burn accents.
- VHS and tape accents.
- Speed ramps.
- Slow motion moments.
- Frame hold impact moments.
- Dark cinematic color grade.
- Neon cyberpunk grade.
- Sharpen and detail pass.
- Noise reduction pass.
