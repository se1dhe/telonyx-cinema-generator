# TELONYX Cinema Generator Product Spec

## Main idea

TELONYX Cinema Generator is an AI post-production web service for movie-based vertical edits.

The user uploads a rough cut for TikTok, Reels or YouTube Shorts, uploads a music track, selects render options and receives a polished premium vertical edit.

## Target content

- Movie edits.
- Character edits.
- Dialogue edits.
- Dark cinematic edits.
- Cyberpunk edits.
- Action edits.
- Loneliness and mood edits.

## User flow

1. Upload rough video cut.
2. Upload music track.
3. Set focus prompt, for example Darth Vader.
4. Select target platform.
5. Select target duration.
6. Enable or disable subtitles.
7. Select subtitle language.
8. Enable or disable transitions.
9. Enable or disable color grade.
10. Enable or disable smart centering.
11. Enable or disable beat sync.
12. Enable or disable cinematic effects.
13. Start render.
14. Track job progress.
15. Download final MP4.

## Render options

- Target platform: TikTok, Shorts, Reels.
- Aspect ratio: 9:16.
- Resolution: 1080x1920.
- Target duration: 15, 25, 30, 45, 60 seconds.
- Subtitle language: auto, ru, en, uk.
- Subtitle style: cinematic, dialogue, aggressive, minimal.
- Color preset: dark cinema, cyberpunk neon, vader red, drive night, neutral.
- Transition style: hard cut, glitch, flash, whip, tape.
- Beat sync: off, soft, strict.
- Centering mode: off, action, face, object.
- Effect intensity: low, medium, high.

## Premium output promise

The final video should feel like a finished short-form edit, not like a simple crop.

The service should improve:

- pacing;
- crop;
- rhythm;
- subtitles;
- color;
- transitions;
- impact frames;
- final export quality.
